# 🐶 Dog Website

A simple website built with TypeScript that displays a cute dog picture.

## Getting Started

### Install dependencies
```bash
npm install
```

### Build the TypeScript
```bash
npm run build
```

### Open the site
Open `index.html` in your browser.

## Features
- Displays a random dog image
- Click **Show Another Dog** to load a new one
- Built with TypeScript + vanilla HTML/CSS
